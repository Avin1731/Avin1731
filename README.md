## 🏗️ Architecture & Workflow

> "I believe in structured, maintainable codebases."

Here is how I typically structure my **Next.js** applications to ensure scalability and cleanliness:

```text
src/
├── app/                  # Pages & Routes (App Router)
├── actions/              # Server Actions (Backend Logic)
├── components/
│   ├── ui/               # Shadcn atomic components
│   ├── layout/           # Navbar, Footer, Sidebar
│   ├── dashboard/        # Admin specific (Forms, Tables)
│   ├── emails/           # React Email templates
│   ├── home/             # Landing page sections
│   └── animation/        # Reusable motion wrappers
├── lib/                  # Utilities, DB config & Auth setup
└── db/                   # Drizzle schema & migrations

```
